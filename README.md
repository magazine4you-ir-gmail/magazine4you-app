# اپ اندروید «مجله بیت کوین»

اپ اندروید (Kotlin) که سایت شما را نمایش می‌دهد: **https://magazine4you.ir/**

## امکانات
- نمایش کامل سایت داخل WebView
- اسپلش اسکرین با لوگو
- Pull-to-refresh + دکمه Back گوشی برای برگشت در تاریخچه سایت
- صفحه خطا با دکمه «تلاش مجدد»
- لینک‌های خارج از دامنه سایت در مرورگر گوشی باز می‌شوند

## روش ساخت APK با گیت‌هاب (بدون نیاز به نصب Android Studio)

این پروژه یک فایل GitHub Actions (`.github/workflows/build.yml`) دارد که به‌صورت خودکار
بعد از هر Push، اپلیکیشن را می‌سازد و فایل APK را برایتان آماده می‌کند.

### قدم ۱: ساخت ریپازیتوری در گیت‌هاب
1. وارد GitHub بشید → دکمه سبز **New** (یا آیکون + بالای صفحه) → **New repository**
2. یک اسم بدید، مثلاً `bitcoin-magazine-app`
3. آن را **Public** یا **Private** بگذارید (فرقی نمی‌کند)
4. تیک «Add a README file» را **نزنید** (چون خودمان README داریم)
5. روی **Create repository** بزنید

### قدم ۲: آپلود پروژه
ساده‌ترین راه (بدون نیاز به خط فرمان):
1. فایل zip پروژه را از حالت فشرده خارج کنید تا پوشه‌ی `BitcoinMagazineApp` را ببینید
2. داخل صفحه‌ی ریپازیتوری خالی که ساختید، روی لینک **uploading an existing file** کلیک کنید
3. تمام فایل‌ها و پوشه‌های داخل `BitcoinMagazineApp` را بکشید و رها کنید (Drag & Drop) — از جمله پوشه‌ی مخفی `.github`
   - نکته: مرورگرها معمولاً پوشه‌ها را هم قبول می‌کنند؛ اگر پوشه‌ی `.github` آپلود نشد، طبق «قدم ۴» زیر آن را جداگانه از طریق «Create new file» بسازید.
4. پایین صفحه، دکمه‌ی سبز **Commit changes** را بزنید

یا اگر با Git کار می‌کنید (روش حرفه‌ای‌تر):
```bash
cd BitcoinMagazineApp
git init
git add .
git commit -m "اولین نسخه اپ مجله بیت کوین"
git branch -M main
git remote add origin https://github.com/USERNAME/bitcoin-magazine-app.git
git push -u origin main
```
(`USERNAME` و اسم ریپازیتوری را با مقادیر واقعی خودتان جایگزین کنید)

### قدم ۳: دانلود APK ساخته‌شده
1. داخل ریپازیتوری‌تان روی تب **Actions** کلیک کنید
2. یک ورک‌فلو به اسم **Build APK** می‌بینید که به‌صورت خودکار شروع به اجرا شده (چند دقیقه طول می‌کشد)
3. وقتی تیک سبز خورد، روی همان اجرا (run) کلیک کنید
4. پایین صفحه، بخش **Artifacts** را ببینید → روی **app-debug-apk** کلیک کنید تا دانلود شود
5. فایل zip دانلود‌شده را باز کنید؛ داخلش `app-debug.apk` است
6. این APK را به گوشی اندرویدتان منتقل و نصب کنید (باید «نصب از منابع ناشناس» را فعال کنید)

> اگر بعداً هر تغییری در کد یا لوگو دادید و دوباره Push/Commit کردید، این فرآیند خودکار دوباره اجرا می‌شود و APK جدید در Actions آماده می‌شود.

## تغییر لوگوی اپ (خیلی مهم)

برخلاف نسخه‌ی قبلی، الان لوگو و آیکون‌ها به‌صورت فایل‌های **PNG ساده** هستند (نه کد وکتور)،
پس جایگزین کردن‌شان از طریق وب‌سایت گیت‌هاب هم خیلی راحت است — فقط کافیست
فایل جدید را با **همان اسم** آپلود کنید تا فایل قدیمی جایگزین شود (Overwrite).

### فایل‌هایی که باید جایگزین کنید:

**۱. آیکون اپ (که زیر آیکون‌های گوشی دیده می‌شود)**
باید در ۵ سایز مختلف (برای رزولوشن‌های مختلف گوشی) با اسم دقیقاً `ic_launcher.png`
و `ic_launcher_round.png` در این مسیرها قرار بگیرد:

| پوشه | سایز پیشنهادی |
|---|---|
| `app/src/main/res/mipmap-mdpi/` | 48×48 پیکسل |
| `app/src/main/res/mipmap-hdpi/` | 72×72 پیکسل |
| `app/src/main/res/mipmap-xhdpi/` | 96×96 پیکسل |
| `app/src/main/res/mipmap-xxhdpi/` | 144×144 پیکسل |
| `app/src/main/res/mipmap-xxxhdpi/` | 192×192 پیکسل |

اگر وقت/حوصله‌ی ساخت ۵ سایز مختلف را ندارید، کافیست همان یک لوگوی
با کیفیت بالا (مثلاً 512×512) را در هر ۵ پوشه با همین دو اسم آپلود کنید؛
اندروید خودش آن را برای هر گوشی مقیاس می‌دهد (کیفیت روی گوشی‌های بزرگ‌تر کمی افت می‌کند ولی کار می‌کند).

نحوه‌ی آپلود در گیت‌هاب: وارد پوشه‌ی موردنظر (مثلاً `mipmap-xxxhdpi`) بشوید →
روی فایل قدیمی `ic_launcher.png` کلیک کنید → آیکون سطل زباله/ویرایش →
یا ساده‌تر: از صفحه‌ی همان پوشه دکمه‌ی **Add file > Upload files** را بزنید و
فایل جدید را با همین اسم دقیق آپلود و Commit کنید (گیت‌هاب خودش جایگزین می‌کند).

**۲. لوگوی صفحه‌ی اسپلش (لوگویی که موقع باز شدن اپ دیده می‌شود)**
مسیر: `app/src/main/res/drawable/splash_logo.png`
پیشنهاد: تصویر مربعی با پس‌زمینه‌ی شفاف (Transparent PNG)، حدود 480×480 پیکسل.

### نکته
- فرمت فایل باید **PNG** باشد (پسوند دقیقاً `.png`).
- اگر Android Studio دارید، راه ساده‌تر: راست‌کلیک روی پوشه‌ی `res` →
  `New > Image Asset`، لوگوی سایت را انتخاب کنید تا همه‌ی سایزها را خودش خودکار بسازد،
  بعد نتیجه را روی گیت‌هاب Push کنید.

## تغییرات دیگری که ممکن است بخواهید بدهید
- **آدرس سایت:** `app/src/main/res/values/strings.xml` → مقدار `site_url`
- **اسم اپ:** همان فایل → مقدار `app_name`
- **رنگ برند (نارنجی):** `app/src/main/res/values/colors.xml` → `bitcoin_orange`
- **مدت اسپلش اسکرین:** `app/src/main/java/ir/magazine4you/bitcoin/SplashActivity.kt` → متغیر `splashDelayMillis`
- **Application ID (برای انتشار در Google Play):** `app/build.gradle` → فیلد `applicationId`

## انتشار رسمی در Google Play
فایلی که از GitHub Actions می‌گیرید نسخه‌ی **Debug** است و فقط برای تست شخصی مناسب است.
برای انتشار در Google Play باید یک نسخه‌ی **Release امضاشده (Signed)** بسازید که نیاز به
Android Studio و ساخت Keystore دارد؛ اگر به آن مرحله رسیدید بگویید تا راهنمایی‌تان کنم.
